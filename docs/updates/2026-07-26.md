# 2026-07-26 System Update

## Overview

Five major areas updated today:

1. **Bear Trap Simulator** - rebuilt around a precise atomic scenario model with optimizer, recommendations, formation surface, and a fully redesigned 9-step guided editor.
2. **Advertising Readiness** - consent handling, policy pages, SEO routes, prerendering, and administrative configuration.
3. **Registration and Identity** - sessions, secure password-reset links, role requests, moderator controls, multi-player links, and player-context improvements.
4. **Analytics** - expanded personal and alliance analytics with centralized visibility rules and corrected dashboard permissions.
5. **Testing and Validation** - expanded validation limits, updated UI tests, and security diagnostics updated to support new workflows.

---

## Bear Trap Simulator

### Engine

The Bear Trap engine was rebuilt around a precise atomic scenario model covering the full stat-layer chain:

- Atomic scenario input with versioned validation, normalization, and source-layer resolution.
- Optimizer and ranked recommendations engine.
- Formation surface generator for ternary troop composition analysis.
- Worker request path for long-running calculations.
- Preset migration from the previous format.

### UI/UX - 2026 Redesign

The Bear Trap simulator frontend was completely redesigned:

**Simulate button placement** - The "Run Bear Simulation" button now appears *after* the Review section (matching the Hero Gear Optimizer pattern), not at the top of the Setup section.

**Simulate Gate** - A large, animated full-width CTA replaces the previous inline button:
- Green gradient border + pulsing icon when the setup is complete and ready.
- Amber border + warning icon when required fields are missing, with a clear message explaining what to fill in.

**Status Bar** - Four compact pills at the top of Setup update live:
- Troops assigned (green if > 0)
- Joiners with active skill count
- Leader heroes configured (3/3 turns green)
- Overall readiness

**Mode Selector** - Compact pill group for Workflow (Build setup / Replay rally) and Role (Leader / Joiner), replacing the large choice cards.

**Review Cards** - Color-coded with a left border accent:
- Green + checkmark icon = section complete
- Amber + X icon = needs attention

**Captain Skills Card** - Rebuilt with four large hero portrait slots (3 rem), skill name, and level badge. Empty slots show a dashed placeholder.

**Hero Avatars in Tables** - Captain skill audit table rows now display the hero portrait inline.

**Share Your Experience** - Enhanced layout with animated Flame icon and a glow + lift hover effect on the share button.

**Results** - Slide-up entrance animation on results reveal. Action bar with Edit setup, Recalculate, and Share result buttons.

**Color Utilities** - Positive values (green), negative values (red), neutral values (muted) throughout the results and review sections.

**Mobile** - Full responsive breakpoints: 1-column at 36 rem or below, 2-column at 60 rem or below. Simulate gate stacks vertically on small screens.

**Compact density** - Input height reduced, field labels use uppercase tracking style, card padding tightened across all Bear sections.

**Dead code removed** - Legacy first-generation hero card and joiner card variants removed. Only the current versions are rendered.

The complete multi-day release is documented in [25-29 July 2026 System Update](2026-07-25-29-system-update.md).
