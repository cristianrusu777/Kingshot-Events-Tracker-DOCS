# Terms
The authoritative service terms are presented in the Kingshot Events application. Review the current terms before creating an account or using a workflow that asks for consent.

This documentation explains product behavior and does not replace the current in-product legal text. If wording differs, use the version presented by the application and contact support through the visible channel.
