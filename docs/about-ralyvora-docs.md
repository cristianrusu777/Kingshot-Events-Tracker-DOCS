# About Ralyvora Docs
Ralyvora Docs is the public product documentation portal for Ralyvora platforms. It explains user-visible workflows, roles, states, limitations, and safe troubleshooting. Kingshot Events is currently the only documented platform.

The documentation is curated from verified product behavior. It does not publish private platform operations, source implementation, confidential formulas, credentials, or real community records.

Ralyvora is an independent community platform and is not officially affiliated with or endorsed by Kingshot or its publisher.
