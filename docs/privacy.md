# Privacy
Kingshot Events stores the account, player, community-scope, event, application, content, profile, subscription, and support information needed for available workflows. The exact data shown depends on the feature and access.

Use the privacy and data-rights controls in the current application for requests and consent choices. Public documentation does not reproduce private records or explain security-sensitive internal handling.

When sending support information, share only what is necessary. Do not publish screenshots containing real email addresses, player identifiers, private rosters, payment information, or credentials.
