# User-facing Release Notes
## August 2026 documentation reconstruction

Ralyvora Docs now uses a platform portal, a dedicated Kingshot Events namespace, curated navigation, role-based journeys, consolidated troubleshooting, and explicit publication controls. Technical repair notes, testing instructions, permission catalogs, private administrator material, and obsolete screenshots were removed from public documentation.

## July 2026 product direction

Recent user-facing areas include the expanded Lab with progression and combat tools, Knowledge Hub reading and authoring surfaces, Reading Verification, Castle Position workflows, subscriptions and usage views, updated navigation, and public policy pages. Availability still depends on account, scope, role, subscription, and module state.

Release notes describe user-visible changes only. Product behavior shown in the current interface takes precedence over older documentation.
