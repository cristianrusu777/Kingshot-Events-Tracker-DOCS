# Choosing Scope and Understanding Access
Access answers two questions: what may this account do, and in which kingdom or alliance may it do it? The interface combines both answers when it builds navigation and actions.

## Choose the correct scope

When a selector is available, choose the kingdom or alliance that owns the information. Re-check it before creating a player, applying an import, reviewing event records, or publishing a schedule. A saved item can be correct in form but wrong in context.

## Find your way around

**Workspace** contains active records and event views. **Discover** contains Updates, Knowledge Hub, and Lab tools. **My Tools** contains personal rewards or appointment actions. **Input** contains manual entry, imports, and reports. Management and settings groups appear only when the current assignment allows them.

A missing action usually means the current role, scope, subscription, or module state does not make it available.
