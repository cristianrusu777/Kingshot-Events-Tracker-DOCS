# Activity, Player, and Event Analytics
Analytics summarizes information already available to the current user. Personal views focus on the linked player. Alliance and kingdom views require the corresponding assignment.

Check the scope, date range, event selection, and active filters before interpreting a chart or table. Missing data usually means the underlying player or event records are absent, outside the selected range, or unavailable to the current scope.

Analytics supports review; it is not a substitute for checking source records when a decision has consequences.

<RolePerspective>

### As a player

Read personal summaries in the context of the linked player and selected date range.

### As an alliance or kingdom manager

Confirm the community scope and filters, then trace unexpected values back to saved event records.

### What the platform does automatically

It summarizes eligible records for the current viewer; it cannot fill gaps in missing or incorrect source data.

</RolePerspective>
