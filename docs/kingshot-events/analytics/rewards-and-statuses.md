# Reward Eligibility and Statuses
Reward views use saved event information and configured reward rules. A player can see **My Rewards** when available; authorized managers may review broader reward lists or rules.

Eligibility can depend on participation, score, event, date, scope, and configured thresholds. A displayed status reflects the current records and rules, not an unconditional promise of an external in-game reward.

Before changing a decision, check the contributing event records. If a record is corrected, allow the view to refresh and verify the resulting status.
