# Activity, Attributes, Removal, and Restore
Player records may include activity state, manually managed attributes, nickname history, and soft-deletion status. These values support filters, analytics, rewards, and review workflows.

## Activity and attributes

Use the labels shown in the current form. Some attributes are configured for the community and may not appear in every scope. Activity is an interpretation of available records and configured behavior; check the relevant dates before using it for a decision.

## Removal and restoration

Removing a player from ordinary lists is a soft delete. Historical information can remain connected while the record is hidden from active work. Restoration may require an authorized request or recycle workflow. Do not create a replacement player merely because the original is absent from the default list.
