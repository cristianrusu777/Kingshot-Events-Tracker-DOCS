# Player Directory and Profiles
The **Players** directory is the shared roster for the active scope. Use search and filters to locate a player before creating a record. Open a player to review the information, event history, attributes, nicknames, and actions available to your assignment.

## Before you change a player

Confirm the alliance and kingdom, search for alternate spellings or nicknames, and check whether the player is inactive or removed from ordinary lists. This prevents duplicate records.

## Profile results

Changes that save successfully become part of the scoped player record. Event history remains tied to the player. Personal account profile information is separate from the shared player profile.
