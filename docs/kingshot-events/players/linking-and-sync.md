# Player Linking and Synchronization
A player link associates a signed-in account with the matching scoped player. A link request may require manager review. Accepting a link enables eligible personal views; it does not make the account a community manager.

Synchronization updates supported player information between the linked account and record. Review any preview or changed values before confirming. Nickname history helps locate a player after an in-game name change.

## Avoid incorrect links

Check the kingdom, alliance, current name, and known nickname before submitting or reviewing a link. If two plausible records exist, pause and ask the appropriate manager to resolve the duplicate.
