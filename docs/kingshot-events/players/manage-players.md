# Adding and Updating Players
Use **Players** for shared roster maintenance or **Manual Input** when the current workflow presents a player-entry form. Required fields and actions depend on access.

## Core workflow

1. Select the intended alliance scope.
2. Search for an existing record and nickname matches.
3. Choose **Add player** only when no correct record exists.
4. Enter the visible identity and supported attributes.
5. Review the values, save, and confirm the success state.
6. Open the profile to verify the record.

Updating a player changes the current record; it should not erase valid event history. If the save reports a conflict or duplicate, return to the directory and open the existing player.
