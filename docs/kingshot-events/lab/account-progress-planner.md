# Account Progress Planner
The Account Progress Planner compares supported systems using an active profile, owned resources, and optional budget inputs. It can present modeled allocations and bottlenecks across systems.

Confirm every starting level and inventory value, choose the supported planning mode, then review the resulting allocation. Treat pack valuation and cross-system comparisons as planning assumptions, not purchasing advice or guaranteed in-game value.

The planner can be hidden when its own availability setting is off. Saved profile information is not deleted when a tool is temporarily unavailable.
