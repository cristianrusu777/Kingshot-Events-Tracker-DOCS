# Account Progress Planner

The Account Progress Planner compares supported progression systems from one active Lab profile. It helps answer which modeled checkpoint fits a stated inventory or budget, not what a player should purchase.

## Prepare inputs

Select the intended profile and review every included system. Correct starting levels, equipment states, troop bonuses, and inventory. Choose inventory-only or the visible budget or pack-planning mode. Exclude resources you do not own unless the scenario explicitly models acquiring them.

## Run and read the plan

Set the objective and any supported system limits, then calculate. The output can allocate resources across systems, show proposed checkpoints, total modeled cost, remaining inventory, and bottlenecks. Expand each recommendation to verify prerequisites and why it was selected.

Cross-system comparisons rely on declared assumptions. Pack contents, prices, game balance, and account priorities can change. Treat the budget output as scenario analysis, not financial advice or an in-game value guarantee.

## Persistence and availability

Save changed inputs to the Lab profile when you want later modules to reuse them. If the planner is unavailable, the module card explains the state; existing profile data remains available to other supported modules and is not deleted merely because this tool is hidden.
