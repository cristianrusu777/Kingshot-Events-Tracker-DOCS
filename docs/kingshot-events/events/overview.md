# Event Tracking Overview
An **Event Template** describes a reusable event. An **Event Instance** is one scheduled occurrence. Records and results belong to that occurrence. This distinction prevents scores from different dates being mixed.

Managers can configure or review supported events when authorized. Players may see personal event views. The platform may provide templates for common event types, but the visible fields and scoring behavior come from the configured event.

Before entering data, open the correct instance and confirm its date, stages, scope, and scoring mode.
