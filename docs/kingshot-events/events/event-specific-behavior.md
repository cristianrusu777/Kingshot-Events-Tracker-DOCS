# Event-Specific Behavior
The current product includes reusable event templates, instances, result records, event updates, and a **KvK Prep** workspace. Supported event names include common community events, but each configured template determines the fields shown.

KvK preparation can organize phase-specific inputs and review. Bear Trap also has a separate Lab simulator; simulated damage is not the same as a saved event result.

When an event page asks for stages, dates, or records, follow that configuration instead of assuming another event's workflow applies. If an expected field is missing, verify the event instance and its settings with the authorized manager.
