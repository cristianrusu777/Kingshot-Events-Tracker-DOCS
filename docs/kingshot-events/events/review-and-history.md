# Reviewing Results and Event History
Result review connects the submitted source to the structured rows that analytics, rewards, and reports may later use. Check player identity, event instance, date, stage, participation state, and score.

## After review

Accepted or saved records become visible in eligible event and player histories. Corrections should update the intended record rather than create a second occurrence. A locked session or finalized workflow may prevent changes; contact the authorized event manager instead of starting a duplicate session.

Players can use personal event history to understand recorded activity. Managers can use scoped records to investigate missing or unexpected summaries.
