# How Scopes Work
A scope is the kingdom or alliance context in which a task is performed. The same account can have different responsibilities in different scopes.

## Scope-sensitive actions

Player creation, imports, event records, analytics, reward review, Knowledge content, reports, and Castle Position management can all depend on scope. Confirm the selector and page heading before acting.

## Visibility

Authorized kingdom users may see cross-alliance views. Alliance managers normally work only with assigned alliances. Players see personal or specifically shared information. Changing the selected scope changes the records shown; it does not move records between communities.
