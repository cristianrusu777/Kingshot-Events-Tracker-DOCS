# Alliance Leader or Co-leader
Maintain the assigned alliance roster, review contributions, enter or import event information, verify results, and use scoped reports. A co-leader sees only actions included in the assignment.

## Recommended sequence

1. Sign in when the workflow requires it and confirm profile information.
2. Select the correct kingdom or alliance scope.
3. Open the page named in the current navigation.
4. Review inputs and status before saving, submitting, accepting, or publishing.
5. Verify the result in the destination view.

## When to ask for help

Contact the community manager responsible for the current scope when information is missing or an action is unavailable. Contact platform support only after checking the account, scope, role assignment, feature availability, and visible error.

## Practical depth

### Your recurring path

Maintain membership and activity, prepare event work, review imports, close corrections, reproduce analytics with named filters, make reward rules visible, and confirm member-facing outcomes.

For your recurring path, read the current status and confirmation on the source record before acting again. If two people see different results, compare identity, scope, role, filters, date window, and publication version. Preserve the record name, visible message, approximate time, and safe steps to reproduce. Note whether refreshing or reopening changed the observation, but do not repeat an irreversible action as a test. Never include credentials, payment information, private exports, or unrelated player data in support evidence.
