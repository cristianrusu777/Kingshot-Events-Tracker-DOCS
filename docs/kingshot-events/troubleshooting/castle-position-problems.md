# Castle Position Problems
## What you see

An application link fails, a status is unclear, or an appointment differs from an earlier view.

## What it usually means

The instance may be closed, the code invalid, the application updated, or a newer schedule published.

## Safe checks and resolution

Use the latest link, confirm the instance, check My Appointments and the latest published schedule, then contact the kingdom organizer.

## When to contact an authorized manager

Ask for help when the issue depends on role assignment, community scope, review status, or a locked workflow. Include the page name, visible message, selected scope, approximate time, and the safe steps already tried. Do not include passwords, tokens, private keys, or unrelated personal data.

## Practical depth

### Check the appointment cycle

Compare kingdom, position, eligibility, capacity, application status, planner conflict, published version, and notice. A draft schedule is not authoritative.

For check the appointment cycle, read the current status and confirmation on the source record before acting again. If two people see different results, compare identity, scope, role, filters, date window, and publication version. Preserve the record name, visible message, approximate time, and safe steps to reproduce. Note whether refreshing or reopening changed the observation, but do not repeat an irreversible action as a test. Never include credentials, payment information, private exports, or unrelated player data in support evidence.
