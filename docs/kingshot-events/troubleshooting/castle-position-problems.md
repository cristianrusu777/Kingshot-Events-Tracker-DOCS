# Castle Position Problems
## What you see

An application link fails, a status is unclear, or an appointment differs from an earlier view.

## What it usually means

The instance may be closed, the code invalid, the application updated, or a newer schedule published.

## Safe checks and resolution

Use the latest link, confirm the instance, check My Appointments and the latest published schedule, then contact the kingdom organizer.

## When to contact an authorized manager

Ask for help when the issue depends on role assignment, community scope, review status, or a locked workflow. Include the page name, visible message, selected scope, approximate time, and the safe steps already tried. Do not include passwords, tokens, private keys, or unrelated personal data.
