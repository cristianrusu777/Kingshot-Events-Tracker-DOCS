# Castle Position Applicant Guide
Open the application link shared for the active Castle Position workflow, identify yourself using the requested information, and review the available stages or positions. Submit only after confirming your choices.

The result page can show that the application was submitted or updated. Return through **My Appointments** when available to follow assigned appointments. Accepted, standby, review-required, or other visible states are decisions in the workflow, not a guarantee before publication.

If the form is closed or the code is invalid, contact the kingdom organizer who shared it.
