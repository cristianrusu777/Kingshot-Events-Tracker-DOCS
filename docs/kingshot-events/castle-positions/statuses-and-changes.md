# Castle Position Statuses and Changes
Visible states can distinguish a saved or submitted application, a result that requires review, standby or accepted outcomes, planned appointments, and a published schedule. The exact labels shown in the current instance are authoritative.

An updated application can replace the player's prior choices before the workflow closes. A later manager change should be reflected in the schedule state. Applicants should rely on the latest published result, not an earlier message or draft view.

When a status appears inconsistent, include the instance name, visible status, and approximate update time in a support request.
