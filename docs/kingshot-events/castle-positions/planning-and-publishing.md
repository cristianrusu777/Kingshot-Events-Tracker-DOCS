# Planning, Scheduling, and Publishing
Use the planner for the selected Castle Position instance. Review applications and conflicts, place accepted applicants into supported stages and times, and inspect the complete schedule before publication.

Publishing changes the schedule from a manager workspace into the result intended for participants. If later changes are allowed, record them through the current workflow and make sure affected players can see the updated result.

Automatic placement is a suggestion based on the available inputs. Managers remain responsible for checking availability, conflicts, and fairness.
