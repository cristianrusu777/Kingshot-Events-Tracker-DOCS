# Castle Position Review Workflow
Authorized reviewers open **Castle Positions Admin**, choose the current instance, and assess submitted preferences and any visible conflicts. Reviewers assign the supported status or placement outcome and record changes before planning.


<RolePerspective>

### As an applicant

Wait for the visible status and published schedule; avoid submitting duplicate applications.

### As a reviewer

Verify identity, choices, timing, and conflicts in the selected instance before changing status.

### What the platform does automatically

It preserves applications, review state, and schedule data for the selected workflow. Automated placement, when offered, is a planning aid and still requires review.

</RolePerspective>


Do not treat a computed suggestion as a final appointment.
