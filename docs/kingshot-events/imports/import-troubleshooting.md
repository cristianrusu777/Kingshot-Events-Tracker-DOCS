# Import Troubleshooting
## What you see

The image is rejected, processing does not complete, rows are missing, or the review contains incorrect values.

## What it usually means

The file may be unsupported or unclear, the selected category may not match the image, the module may be unavailable, or recognition needs manual correction.

## Safe checks

Confirm the scope and category, use a clear supported image, keep required labels visible, and retry once. If rows appear, correct them in review instead of uploading repeatedly.

## Ask for help

Include the visible error, approximate time, selected scope, import category, and whether the import reached review. Do not include credentials or unrelated private images.
