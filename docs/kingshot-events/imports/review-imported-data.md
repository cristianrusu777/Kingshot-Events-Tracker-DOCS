# Reviewing Imported Data
The review screen separates extraction from saving. Each proposed row should be matched to the intended player and event context. Correct visible errors, remove unusable rows when the workflow allows it, and apply only after the summary is accurate.

An import can remain in a reviewable state until applied. Restoring a prior draft or reprocessing can replace proposed information; it should not be used to conceal a bad applied record. After applying, verify the destination records and resolve any warnings.
