# Subscription Overview
Subscriptions can make supported premium capabilities available to a direct alliance or through a kingdom allocation. The **Support & Plans** area shows the options and request workflow available to the current user.

A request can move through submitted, reviewed, accepted, or declined states as shown in the interface. Payment or support instructions must come from the configured visible support links; documentation does not invent payment details.

An accepted kingdom grant can make a plan effective for an eligible alliance. Exact features and limits come from the current plan display.

<RolePerspective>

### As an alliance member

Check the effective plan and visible feature availability for the current alliance.

### As a kingdom or alliance manager

Review the requested scope, status, grant, and current usage before changing or escalating access.

### What the platform does automatically

It resolves the effective plan and shows supported warnings. It does not move an entitlement between scopes without an authorized workflow.

</RolePerspective>
