# Contact and Support
Start with the relevant [troubleshooting guides](/kingshot-events/troubleshooting/access-problems). Community managers should handle questions about role assignments, kingdom or alliance scope, event review, reward decisions, and Castle Position schedules.

Use the support or contact link shown in the Kingshot Events application for account or platform issues. This documentation does not publish an unverified email address or payment destination.

## Include

- page or feature name;
- visible status or exact safe error wording;
- kingdom or alliance label when relevant;
- approximate date and time;
- steps already tried.

Never send passwords, access tokens, private keys, payment secrets, or screenshots containing unrelated personal data.
