# Editorial Policy
Public documentation describes confirmed user-visible behavior. When older guidance conflicts with the current interface, the verified product behavior wins. Unfinished or disabled features are not presented as fully available.

Pages use direct language, identify important scope and status behavior, and distinguish assisted processing or estimates from guaranteed outcomes. Strategy content belongs in Knowledge Hub; product documentation explains how to use the platform.

Every published page is registered in the publication manifest and reviewed for links, metadata, accessibility, visual safety, and information leakage. Corrections should identify the page and the observed current behavior without including confidential data.
